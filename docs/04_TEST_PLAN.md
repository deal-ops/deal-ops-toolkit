## 1. 测试分层

| 层 | 工具 | 测什么 | 何时跑 |
|---|---|---|---|
| 单元 | Vitest | §2 中**已到期**（到期里程碑 ≤ 当前里程碑）的 TC；非法输入；格式 | 每次提交（CI） |
| 不变量 | Vitest，固定随机种子批量生成**合法**输入（两种费用口径 × 各种费用组合 × 三种币种） | 每人：已收 = 投资 + 各项费用 + 退款；退款 ≥ 0；每一项费用的各人分摊之和 = 该项总额；投资总额 ≤ 上限；未参与者投资和费用为 0；退出：投资人 + carry + 退出费用 = 回款；按份额拆分之和 = 投资人总额 | 每次提交 |
| 独立复算 | Python（只用标准库 `fractions` / `decimal`），**按 PRD 文字实现，不看 TS 代码** | 已到期的手算案例 + 示例交易 + 不变量的同一批随机输入，与 TS 逐行逐字段对比 | M1 起每次提交（CI） |

| 变异检查 | `scripts/mutation-check.mjs` | 故意改坏关键代码（取整方向、边界、比较符、费用、复核、转义等），每一处都必须被至少一个测试抓住 | 交 Codex 前（自测关卡）、改核心计算时 |
| 性能 | Vitest bench | 上限规模（500 人 / 2,000 行）各模块耗时，记录到 `docs/perf.md` | M1、改算法时 |
| 端到端 | Playwright（M2 起） | §4 | 每个 PR 预览、发布前、上线后 |

**退出分配**（持仓来自上面的快照）：回款 £390,000；退出费用 £4,500；6 年；k 20%；h 8%；c 100%。
- 可分配 £385,500.00；退还本金 £100,395.00；利润 £285,105.00
- hurdle：100,395 × (1.08⁶ − 1) = 100,395 × 0.586874322944 = **£58,919.25**
- catch-up：0.2 × 58,919.25 ÷ 0.8 = **£14,729.81**（全归发起人）
- 剩余 £211,455.94，发起人 20% = **£42,291.19**
- **carry 合计 £57,021.00**（= 285,105 × 20%）；投资人合计 **£328,479.00**

其余每一行（份额、各人退出所得）在 M1 由 TS 与 Python 两套实现生成，一致且负责人抽查通过后，写进 `src/lib/sample.expected.json` 冻结；之后任何改动导致不一致即 CI 失败。

## 6. 导出格式
- 对账台账：`transaction_id, date, amount, payer, reference, status, investor_id, investor_name, decided_by(auto|person)`；v0.8 加 `withdrawn_on`
- 追款清单：`investor_id, name, email, committed, received, difference, status`；v0.8 起 `committed` 为有效应打款额，加 `committed_original, committed_adjustment, message`
- 操作记录（v0.8）：`seq, time, initials, event, investor_id, investor_name, transaction_id, amount, detail, currency`
- 关闭分配：`investor_id, name, scheme, received, invested, units, fee_<每项费用名>, fees_total, refund, seis_eis_claimable_shares, seis_eis_claimable_amount, status`
- 退出分配：`investor_id, name, capital, shares_display, distribution, profit, multiple_excl_entry_fees`（只用于阅读，不用于再导入）
- **导出持仓**（可再导入）：`investor_id, name, capital, shares_display, share_price`。再导入时只取 `capital` 和 `share_price`。
- 金额为不带货币符号的小数（如 `1234.56`），负数保留前面的负号；文件名包含币种（如 `allocation_GBP.csv`）。
- 每种导出的最后一列为 `currency`，每行写交易币种的 ISO 代码（如 `GBP`）；列名固定，不随币种变化（v0.7.5，决定 10）。例外（v0.8）：操作记录每行写**该事件发生时**的币种。
